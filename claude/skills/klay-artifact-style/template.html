Lost Uploads

Platform · File storageError UPL-017TICKET-123

The client uploads a document and sees "done". We never store it. Support then asks the client to upload again.

~40lost files per day
281lost files in 7 days
Web · iOSapps hit

What goes wrong

We answer "done" before the file is stored. If storing fails after that, nobody knows.

Real example

One client uploaded 3 files in one minute. Only the first was stored.

Why the file is not stored

WebTab closes early
The client closes the tab after "done". The upload stops halfway.
iOSApp goes to background
The phone pauses the app. The connection drops.

The fix

We answer "done" only after the file is stored.

Before
// 1. Answer first
res.status(200).send()
// 2. Store later
await storage.put(file)
After
// 1. Store first
await storage.put(file)
// 2. Then answer
res.status(200).send()
